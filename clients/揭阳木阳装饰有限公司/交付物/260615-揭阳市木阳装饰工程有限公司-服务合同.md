## 一、服务内容

甲方为乙方提供销冠数字员工获客服务，服务内容包括：

| 服务项目 | 服务说明 |
|----------|----------|
| 企业资料整理 | 整理乙方企业信息、主营业务、服务区域、报价口径、施工卖点等内容 |
| 素材整理上传 | 整理乙方提供的工地、案例、门店、材料、客户评价等素材，并按用途分类上传 |
| 视频获客 | 围绕装修业务生成首批获客视频内容，用于乙方账号发布和投放测试 |
| 广告投流 | 协助乙方搭建广告计划，跟进消耗、留资、单条成本等数据 |
| 抖音搜索 | 围绕乙方装修业务关键词整理内容，提高乙方在抖音搜索场景中的曝光机会 |
| AI推荐 | 围绕豆包、DeepSeek、Kimi、元宝等平台常见提问，整理乙方可被推荐的业务内容 |
| 抖音来客配置 | 协助乙方开通或配置抖音来客、本地推、线索组件、留资路径等基础能力 |
| 私信和线索承接 | 配置乙方私信接待口径、留资承接路径和基础回复话术 |
| 数据复盘 | 跟进视频发布、广告消耗、留资数量、单条成本等数据，并提出下阶段执行动作 |

## 四、双方权责

### 甲方责任

1. 按本合同约定为乙方提供获客服务。
2. 协助乙方整理企业资料、内容素材、账号配置和广告测试。
3. 对乙方经营数据、客户线索、账号信息进行保密。
4. 涉及价格、工期、材料、施工承诺等内容，发布前应以乙方确认为准。
5. 不承诺固定获客数量、固定成交金额或固定广告成本。

### 乙方责任

1. 按时支付服务费用。
2. 及时提供营业执照、法人身份资料、抖音账号、手机号验证码、门店信息、案例素材、施工素材、客户评价等服务所需资料。
3. 保证提供的案例、图片、视频、评价、证照等资料真实、合法、可用于对外展示。
4. 负责及时接听电话、回复私信、跟进表单线索。
5. 平台投流广告费由乙方自行充值到广告账户，甲方负责执行和数据跟进。
6. 如乙方业务价格、服务区域、施工承诺、售后政策发生变化，应及时通知甲方调整内容。

---

## 五、验收标准

首期服务满足以下事项，即视为完成基础上线验收：

1. 乙方企业资料已录入。
2. 素材已完成基础分类。
3. 首批获客视频已生成。
4. 广告账户具备创建计划条件。
5. 私信或留资路径能够正常承接客户。
6. 每日数据可查看、可记录。

---

## 六、合同终止与退款

1. 乙方单方提前解除合同的，已服务期间费用不退；未开始服务的月份，双方可协商折抵或退还。
2. 甲方未按本合同约定提供服务，乙方有权要求甲方补做；经双方确认无法补做的，按未服务月份协商退款。
3. 因乙方未按时提供资料、未配合账号验证、未接客户线索、广告账户审核失败、平台规则变化等非甲方原因造成的服务延误或效果波动，不视为甲方违约。
4. 双方协商一致可提前终止合同，并按实际服务情况结算。

## 七、其他约定

1. 本合同一式两份，双方各执一份，具有同等法律效力。
2. 本合同未尽事宜，双方可另行签署补充协议，补充协议与本合同具有同等法律效力。
3. 执行过程中如有争议，双方应先友好协商；协商不成的，提交甲方所在地人民法院管辖。
4. 本合同自双方签字或盖章，且乙方首期服务费到账之日起生效。
