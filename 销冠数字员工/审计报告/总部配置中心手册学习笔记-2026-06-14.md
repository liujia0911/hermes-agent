- 代理商等级
- 会员数量，也就是数字员工数量
- 算力余额
- SEO 关键词排名
- GEO 引用率

## 3. 权限管理

用途：开放下级代理商。

路径：权限管理 → 管理员管理 → 添加

填写重点：

- 用户名
- 代理商级别
- 邮箱
- 手机号
- 昵称
- 密码
- 状态

总部建议：用户名和手机号一致。

当前我们后台状态：

- 已有 2 个下级渠道代理。
- 只能新增渠道代理 B 级。

## 4. 会员开通

路径：会员管理 → 添加

会员就是客户的数字员工账号。

开通需要：

- 用户名
- 密码，默认可用 123456
- 昵称，填企业名称
- 手机号，用于客户登录
- 行业
- 头像或公司 Logo
- 到期时间
- 企业名称
- 公司地址
- 法人姓名
- 法人手机号
- 营业执照
- 机器人 MAC，有硬件才填

总部说法：如果交付 Funiux 硬件，要给设备通电后询问设备码，再填入机器人 MAC；没有硬件就不用填。

## 6. 营销视频生产

总部要求顺序：

1. 先录入企业信息。
2. 再上传声音、主镜头、素材。
3. 素材要按场景分类并编辑标签。
4. 系统会按企业信息和行业内容自动生成文案。
5. 视频素材会按文案调用。

手动制作视频：

路径：用户配置 → 成品仓库 → 制作视频

填写：

- 提前准备好的文案，一条文案对应一条视频。
- 选择声音。
- 选择主镜头。
- 选择视频模板。
- 选择画中画穿插素材。
- 提交生成。

当前唐宋已有一条视频任务：

- 文案和音频已生成。
- 数字人视频地址为空。
- 剪辑视频地址为空。
- 发布状态未发布。

## 7. 广告账户绑定

总部要求顺序：

1. 先在会员面板进行本地推账号授权。
2. 任意微信扫码登录要绑定的巨量账户。
3. 打开广告户配置 → 广告户列表。
4. 在列表操作里填写企业申请的本地推账户 ID。
5. 本地推账户 ID 在本地推后台右上角查看。

当前唐宋状态：

- 授权二维码已有。
- access_token 为空。
- advertiser_id 为空。
- 说明广告授权还没走完。

## 8. 本地推搭建

路径：用户配置 → 本地推搭建 → 添加模版

填写重点：

- 计划名称
- 投放路径：私信消息、私信留资、营销页
- 预算：不得低于 300，这是巨量平台要求
- 抖音 ID
- 留资组件 ID
- 商品 ID
- 年龄
- 性别
- 推广时间段
- 留资小卡片
- 投放地区

总部建议：

- 私信消息适合个人 IP。
- 私信留资适合获取客资。
- 营销页适合精准客户。
- 全国投放时，地区选择不限后提交。
- 发布作品二维码里选择付费投流；巨量本地推后台出现计划，才算搭建完成。

当前唐宋状态：

- 本地推模版 0 个。

## 9. SEO 排名推送

路径：用户配置 → 抖音关键词管理

先做抖音账号：

1. 打开抖音账号。
2. 点击添加。
3. 昵称不限。
4. UID 填电脑端抖音主页 URL 里的 UID。
5. 刷新后看到账号，即绑定成功。

再看关键词：

- 关键词管理列表可查看账号视频对应关键词话题排名。

## 13. NFC 硬件交付

前提：有硬件交付。

手机端：

1. 苹果手机下载 NFC Tools。
2. 打开后点“写”。
3. 添加记录。
4. 选择 URL/URI。

后台端：

1. 找到要配置硬件的会员。
2. 微信扫对应发布码。
3. 右上角复制链接。
4. 把链接放入 NFC Tools 的 URL/URI。
5. 点右上角对号。
6. 跳到写入页面，点击写入。
7. 手机提示扫描时贴近设备。
8. 写完后先做碰一碰测试。

## 14. 我们后台优先施工顺序

1. 补代理商参数设置：先把扣费规则建起来。
2. 完成唐宋巨量授权：广告水管先接通。
3. 新建本地推模版：预算按 300 起。
4. 绑定抖音账号：为 SEO 排名准备账号。
5. 添加关键词：让控制台 SEO 有数据。
6. 补外呼配置：需要先拿到企业话术和总部审核结果。
7. 做官网对接：为 GEO 自动发文准备载体。

## 15. 需要向睿哥确认的问题

- 昕冠科技默认扣量参数按总部默认值走，还是按招商体系重新定？
- 唐宋是否已经有巨量本地推账户 ID？
- 唐宋要投放的抖音号 UID 是哪个？
- 唐宋有没有官网；如果没有，GEO 文章发布先暂停。
- 外呼话术是否已给总部审核。
